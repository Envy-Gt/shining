# shining
Description : Shining is an all in one DIY electroplating machine that answers those constraints : It can be used without an external generator with consistent results even with minimum knowledge of the practice, as safe as possible to use and Fully made with only generic parts and a standard 3D printer

 # What’s electroplating ? 

 Electroplating or electroforming consists of using electricity to depose a thin layer of metal (copper, nickel, palladium, gold…) on a conductive piece.
Electroplating can be used in many diy fields like jewelry, electronics or miniatures painting
